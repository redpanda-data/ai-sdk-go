# Model metadata: the shared catalog

Status: shipped (rev 3) · Date: 2026-08-17

Rev 1 and rev 2 were design proposals (rev 2 survives as an exported PDF along with its
10-codebase research notes; the second review's findings are folded in below). This revision
records the design as implemented.

## Shape

One shared read model in `catalog/`; authored shapes live in the provider packages.

- **Identity is layered.** A canonical `catalog.ModelID` ("anthropic/claude-opus-5") names the
  logical model and keys a `Registry` of host-independent `Facts` (label, series, release date,
  knowledge cutoff, open weights). An offering ID ("us.anthropic.claude-opus-5") names one
  invokable row on one provider and carries everything that genuinely varies per host:
  capabilities, constraints, modalities, reasoning controls, speeds, pricing, lifecycle,
  attributes. Facts are *referenced*, never copied — `catalog.New` fails on an
  unregistered ModelID, so two providers cannot drift on the same model (the failure that
  shipped in LiteLLM, Vercel's AI SDK, Grafana's ai-sdk, and Catwalk, and twice in this repo).
- **Derive, never store.** Anything that is a function of the rest of the catalog is computed
  at read time: generation ordering from `Facts.Released` within a `Series` (a non-branching
  succession line — gpt / gpt-mini / gpt-nano are three series); succession from series order
  (`Catalog.Successor`) with provider-announced `Life.ReplacedBy` taking precedence; price
  tiers from the base rate card with absolute thresholds. Adding a model never edits an
  existing entry.
- **Clock-dependent classification lives only on `View`** (`Catalog.At(asOf)` / `.Now()`):
  `Current` / `Previous` (generation, computed per logical model so Bedrock geo variants don't
  compete) are orthogonal to `Deprecated` / `Retired` (lifecycle). Retirement derives
  exclusively from an exact announced `Retires` date, inclusive, UTC date-only; published
  "not sooner than" floors are deliberately not tracked (nothing surfaces them). Artifacts built
  from `Catalog` alone are therefore reproducible.
- **Resolution** (`Catalog.Resolve`) is exact → alias → longest boundary-aware prefix, so
  snapshots ("claude-sonnet-4-5-20250929") and official aliases ("gpt-5.6") resolve
  deterministically. Unknown means *stop enforcing*, never *assume a baseline*: no guessed
  capabilities, and pricing stays `ErrUnknownModel` — never free.
- **Immutability is structural.** `catalog.New` validates (path-qualified, indexed errors) and
  freezes; `Lookup`/`All`/View reads deep-copy (pricing via `pricing.Info.Clone`). An
  architecture test keeps `catalog` linkable without any provider SDK.
## Authoring

Providers author `[]catalog.Entry` in `models.go` (`entries()`), frozen via
`catalog.MustNew` at init. Bedrock authors one `family` declaration per logical model,
expanded into per-profile entries by `families.go`; rates stay authored data (geo and global
cards written out per family) with the AWS 1.10x geo/global relationship pinned by
`TestGeoGlobalRatio` as a tripwire, not derived arithmetic. Provider-local wire detail stays
provider-local: Google's numeric thinking-budget ranges (side table, bijection-tested against
`Reasoning.Budget`), Anthropic's adaptive-thinking wire switch, mantle routing.

The catalog is **append-only**: retired offerings keep their entries (with `Retires` in the
past and `// Deprecated:` markers on their ID constants) so historical usage stays priceable
and failures stay explainable. Claude Opus 4.1, GPT-5.2 Instant, and GPT-5.3 Chat Latest —
all deleted from the old catalogs when they retired — were restored this way.

## Surfaces

- `provider.Catalog() *catalog.Catalog` is the single discovery + pricing surface
  (`llm.ModelDiscoveryInfo`, `Models()`, and `ModelPricing()` are gone — see MIGRATION.md).
  `openaicompat.Catalog()` returns nil by design: its model space is caller-defined.
- **Billing path:** `llm.Response.InvokedModelID` can carry timestamped snapshots; resolve
  through the catalog before `pricing.Catalog.Calculate`. `PricingByID()` includes exact
  aliases. Pinned by `TestBillingResolvesInvokedModelIDs`.
- **Snapshot artifact:** `catalog/snapshot.json` (schema_version 1; deterministic, no
  timestamps, time-independent derivations only), regenerated by `task catalog:snapshot` and
  CI-checked by `task catalog:check`. It is the review diff for every catalog change, the read
  format for non-Go consumers (the gateway console), and the wire format a future
  remote-refresh layer would serve. Tolerant-reader contract: consumers ignore unknown fields;
  the version bumps only on rename/removal/semantic change.
- Conformance: `Fixture.Catalog()`; metadata assertions cover every offering, the live
  generation sweep iterates `Now().Current()` so retirements age out of live coverage
  structurally.

## Follow-ups (deliberately out of the migration)

- Weekly `model-lifecycle-sync` skill + GitHub Action: scrape the four machine-readable
  lifecycle sources (Anthropic/OpenAI/Google deprecation pages, Bedrock
  `ListFoundationModels`), diff against the snapshot, open a PR touching `Life` fields and
  `// Deprecated:` constants only. Nothing auto-merges: once `Current()` and the console
  consume `Retires`, dates are behavioural, and no schema test can prove an LLM read the right
  date off a docs page.
- Per-offering harness `Tuning` defaults (default max output tokens, compaction ceiling) and a
  `ToolOutputCap` (bytes|tokens), once the agent/gateway implements something that acts on
  them. Cut from the migration: shipping the seam before a consumer exists would freeze its
  shape prematurely, and re-adding fields later is non-breaking.
- Remote-refreshable catalog for the gateway (three-tier ladder: remote → disk cache →
  embedded; integrity gate; never fatal; startup may fall back, reload must not). The snapshot
  schema is its wire format.
- `Resolution` diagnostics (match kind, requested-vs-resolved) if the gateway wants
  attribution; PriceTier threshold confirmation with the gateway team ($2.50/$10 blended,
  `(3*input+output)/4`).
